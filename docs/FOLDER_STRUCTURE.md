# Graphify Folder Structure

```text
Graphify-Project/
|
|-- README.md
|-- docs/
|   |-- PROJECT_NOTES.md
|   |-- INSTALLATION.md
|   |-- EXECUTION_STEPS.md
|   |-- FOLDER_STRUCTURE.md
|
|-- screenshots/
|   |-- graphify-screenshot.png
|
|-- graphify-out/
|   |-- graph.html
|   |-- graph.json
|   |-- GRAPH_REPORT.md
|   |-- GRAPH_TREE.html
|
|-- .gitignore
```

## Folder Explanation

- `README.md`: Main project introduction displayed on GitHub.
- `docs/`: Installation, execution, and learning notes.
- `screenshots/`: Images showing the project running.
- `graphify-out/`: Files generated by Graphify.
- `.gitignore`: Prevents selected unwanted or sensitive files from being committed.

The actual repository can contain additional files and folders beyond this simplified structure.
